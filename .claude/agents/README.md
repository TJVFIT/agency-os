# Project subagents

Curated from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)
(230+ personas). We pulled the **10** that map onto real Agency OS modules,
rather than the whole set — more agents = a noisier delegation menu.

| Agent | Maps to |
| --- | --- |
| `marketing-content-creator` | card copy / captions pipeline |
| `marketing-instagram-curator` | Instagram publishing (req 23–24) |
| `marketing-tiktok-strategist` | TikTok publishing (req 25–26) |
| `marketing-social-media-strategist` | cross-client content strategy |
| `marketing-multi-platform-publisher` | Postiz publish dispatcher |
| `marketing-short-video-editing-coach` | reel pipeline + v3 AI video edit |
| `design-brand-guardian` | `clients.brand_profile` voice/tone consistency |
| `support-analytics-reporter` | `/reports` automated reporting (req 35) |
| `project-management-studio-producer` | `/production` shoots/crew/routes |
| `support-finance-tracker` | `/finance` packages/payments/ads (req 32–34) |

To add more, copy another `*.md` from the upstream repo (cloned in scratch during
setup) into this folder. Upstream license: see the source repo (MIT-style).

**Not installed:** the engineering/game-dev/healthcare/GIS/etc. divisions —
irrelevant to a social-media agency and covered by Claude Code's built-ins.
