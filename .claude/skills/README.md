# Project skills

Curated from [kostja94/marketing-skills](https://github.com/kostja94/marketing-skills)
(173 skill files). We installed only the **3** that are genuinely additive for a
Turkish local-business social agency AND have no equivalent already available in
the Claude Code environment:

| Skill | Why |
| --- | --- |
| `local-seo` | Google Business Profile / local search for Ankara restaurants & cafes |
| `translation` | TR↔EN content workflow — matches the app's core translation feature |
| `tiktok-captions` | TikTok caption/script writing — a core publish platform (req 25–26) |

**Why not the full 173?** The environment already ships overlapping skills
(`content-strategy`, `copywriting`, `seo-audit`, `ai-seo`, `paid-ads`,
`social-content`, `programmatic-seo`, `schema-markup`, `launch-strategy`, …).
Dumping the whole repo would register 150+ duplicate skills and make the
delegation menu ambiguous (two `copywriting`, two `content-strategy`, …).

To add another skill, copy its folder (containing `SKILL.md`) from the upstream
repo into this directory. Upstream license: MIT.
